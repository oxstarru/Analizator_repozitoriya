Анализатор репозитория → Markdown

Открой папку репозитория — получи Markdown-документацию по REST endpoints с реальными путями. Что распознано однозначно — в фактах; что не распознано — в сыром виде кода для уточнения с разработчиком.

ШАГ 01 Выбрать папку репозитория
Твой браузер не поддерживает File System Access API. Открой эту страницу в Chrome или Edge.
⌥

Указывай корень репозитория целиком — тогда сканер прочитает все конфиги и общие константы (например, из common) и подставит реальные значения переменных в пути. Ничего не покидает твой ноутбук: браузер читает файлы локально, только на чтение, без выхода в сеть.

ШАГ 02 Какие микросервисы сканировать

Найдены Java-модули с pom.xml или build.gradle и папкой src — возможные микросервисы. Сканер проходит вложенные папки на всех уровнях и не останавливается на родительском модуле. Выбери нужные; заглушки по умолчанию выключены.
