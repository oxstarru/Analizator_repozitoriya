# Analizator_repozitoriya
Утилита для системных аналитиков и разработчиков, которым нужно быстрее разобраться в большом Java/Spring-репозитории и получить отправную точку для документации проекта. Она просматривает папки модулей, ищет REST-контроллеры и методы, описывает входные и выходные данные и формирует набор Markdown-файлов.
